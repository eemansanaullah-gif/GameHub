# 🎮 GameHub — Smart PC Game Discovery Platform

GameHub is a full-stack web platform for discovering PC games, testing hardware compatibility, and connecting with other gamers[cite: 1].

## ⚡ Features
* **Authentication:** Secure login/register with PHP sessions and `bcrypt`[cite: 1].
* **Game Catalogue:** Filter, search, and view game specs & reviews[cite: 1].
* **Recommendations:** Tailored game suggestions based on favorite genres[cite: 1].
* **PC Compatibility Checker:** Scores RAM, GPU, CPU, and storage against game specs[cite: 1].
* **Partner Finder:** Connects players by play style, active hours, and favorite games[cite: 1].
* **Wishlist:** Save and manage personal game collections[cite: 1].
* **Admin Panel:** Manage games, users, reviews, and platform analytics[cite: 1].

* **Frontend:** HTML, CSS, JavaScript[cite: 1]
* **Backend:** PHP, REST APIs[cite: 1]
